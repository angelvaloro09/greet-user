# Greet User

Programa con interfaz gráfica en Java (Swing) que pide un nombre y muestra un saludo.

## Requisitos

- Git
- Java JDK (versión 11 o superior).

## Instalación y Ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/angelvaloro09/greet-user.git
   cd greet-user
   ```

2. **Compilar:**
   ```bash
   javac *.java
   ```

3. **Ejecutar:**
   ```bash
   java Main
   ```
